Как устроена комната

Преподаватель создаёт занятие на своём сервере Colloq. Студенты открывают его ссылку и вводят имя. На обычном семинаре у группы общая тетрадь, общие файлы и одно Python-ядро: переменная из первой ячейки доступна в следующей. Тетрадей в комнате может быть несколько — все они работают в том же ядре.

Что важно знать до старта

Colloq разворачивается на вашем сервере. Этот сайт содержит документацию и описание продукта, а учебная комната открывается по адресу, который выдаёт преподаватель.

Colloq — открытый проект под лицензией MIT, исходный код — на github.com/colloq-edu/colloq; выпуски для установки на сервер публикуются там же, на странице Releases. Чтобы провести занятие на своём компьютере, установите пакет и запустите сервер:

pip install colloq
colloq start

Нужны Node.js 22 или новее и Docker; данные занятий хранятся в ~/.colloq. Инструкции для сервера описывают версионированный процесс с манифестом и образами; они не заменяют проверку конкретного выпуска на вашей машине. Для работы с исходниками есть режим разработки.

Разные комнаты получают отдельные ядра и файловые каталоги. Участники одной комнаты разделяют среду исполнения. Подробности и ограничения — в руководстве по изоляции.
