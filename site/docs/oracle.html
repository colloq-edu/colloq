Оракул

Настройте помощь ИИ, ограничения вопросов и работу с файлами.

Включение на сервере и в занятии

Владелец задаёт провайдера, адрес API, модель и ключ на странице «Оракул». Настройки панели могут переопределять переменные окружения сервера. Используется совместимый с OpenAI API провайдер. Для провайдеров, требующих авторизацию, нужен ключ; Ollama и vLLM могут работать без ключа с доступным серверу endpoint и корректной моделью.

При создании занятия выбирается доступность: «Как настроено для инстанса» (по умолчанию), «Выключен», «Только подсказки» или «Полные ответы». Занятие может только ужесточить режим сервера: если владелец выбрал «Только подсказки», полных ответов в комнате не будет. Позже переключателя этой настройки нет. Если для контрольной ИИ не нужен, создайте отдельную комнату с выключенным оракулом.

Вопросы и контекст

Откройте панель оракула и задайте конкретный вопрос: какую ячейку разбираете, что ожидали и что получили. Код и контекст комнаты могут включаться в запрос, поэтому не помещайте в тетрадь API-ключи или данные, которые нельзя передавать выбранному провайдеру.

Ответы появляются в ленте комнаты. Проверяйте предлагаемый код и объяснения: ответ модели может быть неверным, а режим подсказок и дополнительные инструкции не гарантируют поведение модели.

Режим «Сделать»

Если разрешено правило «Оракул в режиме „Сделать“», оракул может читать, создавать и изменять файлы, запускать код. Доступ может быть у всех, только у преподавателя (по умолчанию) или ни у кого. В режиме «Только подсказки» «Сделать» недоступен никому. В комнате одновременно выполняется одно поручение. Число шагов ограничивает правило «Действий на запрос»: чтение, правка и запуск считаются отдельными действиями. На сервере по умолчанию 24, 0 — без лимита; занятие может только уменьшить конечный лимит сервера. Удалять файлы и папки оракул не может. В режиме «Сделать» разрешённые изменения файлов и ячеек применяются сразу, в пределах прав автора запроса. В режиме «Спросить» предложенное изменение ячейки применяется только после нажатия «Принять». Проверьте выбранный режим до отправки задания.

Отмена имеет границы

Отмена восстанавливает доступные версии файлов. Она не возвращает прежнее состояние памяти Python и не отменяет все последствия уже выполненного кода. Просматривайте изменения до продолжения работы.

Лимиты и расходы

На сервере задаются лимит вопросов на студента в час (по умолчанию 20) и промежуток между вопросами (по умолчанию 0, не больше 300 секунд). Ноль в лимите вопросов отключает оракула во всех занятиях, в том числе для преподавателя. Кроме личного лимита действует часовой потолок на всё занятие: 30 личных лимитов или половина лимита на каждого подключённого, если людей больше 60. Участник, вошедший меньше двух минут назад, ждёт перед первым вопросом. Комната может уменьшить число вопросов и увеличить паузу, но не ослабить серверные ограничения. Пустое значение в правилах комнаты означает настройку сервера; ограничения участников не распространяются на преподавателя.

При использовании платного API расходы относятся к аккаунту владельца провайдера. Для локального endpoint вычислительные ресурсы предоставляет оператор. Не включайте OPEN_SEMINAR_CREATION=true на публичном сервере без осознанной необходимости: анонимное создание через API может позволить чужим людям расходовать ваш лимит.

Оракул о классе

На вкладке «Оракул о классе» в пульте Консилиума спросите своими словами или нажмите быстрый вопрос: «Статус класса», «Кто застрял», «Типичные ошибки», «Разбор решений». Спрашивать можно всегда — даже до того, как кто-нибудь написал первую строку: модель видит текст задания и ячейку над ним. Ответы копятся лентой и видны только преподавателю. Запрос работает и в режиме «Только подсказки», но учитывается в часовом потолке занятия.

Провайдер получает задание, контекст, числа по классу, строки по людям и их решения. Имена учащихся уезжают провайдеру, если на этом Colloq включена настройка «Имена учащихся в запросах к модели» (панель → Оракул, по умолчанию включена). Выключите её, и вместо имён поедут метки S1…SN, а имя подставит сервер уже в готовом ответе. Имена и другие данные внутри самого текста решений передаются в любом случае.

В ответе имена людей подсвечены: нажмите — откроется работа этого человека. Это помощь преподавателю при разборе, а не автоматическое оценивание.

Рядом с полем вопроса — уровень размышлений: «сразу», «обычно», «подробно». «Обычно» ничего не добавляет к запросу, «сразу» просит модель ответить коротко и не рассуждать вслух, «подробно» даёт ей думать дольше. Умолчание задаётся в панели; понизить уровень может любой участник, поднять — только преподаватель. У моделей, для которых рассуждение неотключаемо, «сразу» даёт короткий ответ, но не более быстрый — быстрее будет другая модель.

Если ответа нет

Проверьте текст отказа. Каждая причина требует своего действия: исчерпан личный лимит или часовой лимит занятия, не выдержана пауза между вопросами, участник вошёл меньше двух минут назад, в комнате слишком много одновременных запросов, уже выполняется другое поручение «Сделать», занятие закончено, оракул выключен или провайдер вернул ошибку. Владелец проверяет ключ, адрес, модель и доступ сервера к API. Не вставляйте ключ в чат комнаты для диагностики.
